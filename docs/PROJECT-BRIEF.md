# ApexForge – Project Brief (original)

*The founding brief, kept as written. Where the build deliberately differs (D1 instead of local SQLite, webhooks instead of email, Koinos optional and USD for payments), the reasoning is in [PLAN.md](PLAN.md).*

## Mission

Build a fully automated, near-zero-cost system that generates professional, SEO-dominant websites whose sole purpose is to produce high-intent, high-quality leads in life insurance, mortgage lending, and real-estate purchase/sale. The operator will either call the leads directly or resell them to licensed agents/brokers. The same engine must be architected so it can later be productized for other users requesting their own lead platforms, still with no standing monthly bills.

## Primary verticals (start here)

1. Life insurance (term, whole, final expense – emphasize high intent / high qualification)
2. Mortgage lending (purchase, refinance, HELOC)
3. Real estate (buyer and seller leads)

### Additional high-value verticals

4. Medicare Advantage / Medicare Supplement
5. Solar installation (residential)
6. Personal injury legal
7. Financial planning / annuities / retirement

## Monetization model (path to $50k+ monthly)

- **Primary:** Sell qualified leads to licensed agents. Pricing: $25–$80 per life-insurance lead, $40–$120 per mortgage lead, $30–$100 per real-estate lead (quality-dependent).
- **Secondary:** Operator closes deals personally for commission (if licensed or via referral).
- **Tertiary:** One-time sale of white-label lead platforms or appointment-setting services.
- **Volume math example:** 800–1,500 qualified leads/month across verticals at blended $40–$60 = $32k–$90k. Organic SEO traffic is the volume engine; paid traffic is optional later.
- **Koinos layer:** Lead purchase, acceptance, and payment events settle on-chain with KOIN (or future stablecoin) using mana (no gas fees). Creates auditable ownership and can later power a marketplace.

## Zero-recurring-cost rules

- Hosting: Cloudflare Pages or GitHub Pages (free).
- Sites: Fully static (Astro recommended).
- AI: Local Ollama on the 3070 Ti first; free API tiers (Groq, Gemini free, OpenRouter free models) as fallback. No standing subscriptions.
- Forms/CRM: Email delivery + simple local SQLite or JSON. Scale later only if revenue justifies a cheap VPS.
- Only expected hard cost: domain names (~$10–15/year each).
- Expand spend only after proven revenue.

## Recommended technical approach

- **Site generator:** Astro + Markdown/MDX content generated by AI. Programmatic pages for cities, services, and long-tail keywords.
- **SEO:** Schema markup, local SEO, E-E-A-T signals, internal linking, fast Core Web Vitals.
- **Lead capture:** Clean forms → instant notification + stored record.
- **Operator interface:** Simple local dashboard showing new leads, status, and resale price.
- **Koinos integration:** koilib (JS/TS) and AssemblyScript contracts for lead events, payments, and simple CRM state. Invisible wallet experience; mana keeps everything fee-less for users.
- **Deployment:** One-command static build → Cloudflare Pages.

## Koinos strategy

- Fee-less transactions via mana (regenerates based on KOIN held).
- Record lead creation, qualification, purchase, and acceptance on-chain for auditability and a future marketplace.
- Payments in KOIN (or bridged stablecoin when available).
- Use upgradable contracts and Web2-like UX without forcing users to understand blockchain.

## Operator workflow

1. Generate vertical-specific site(s) with AI content + local SEO.
2. Deploy to free hosting + custom domain.
3. Capture leads.
4. Call or package for resale.
5. Optionally settle resale on Koinos.
